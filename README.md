# GŠTK teorijos testas

Interaktyvus testas „Ginklo šaulio tarnybai kurso“ teorijai (teisinis reguliavimas, 1–4 dalys).

- 368 klausimai, 11 temų
- Atsakymas įvertinamas iškart, su paaiškinimu
- Skaičiuojami teisingi atsakymai, klaidos ir tikslumas
- Rezultatai pagal temas, klaidų peržiūra ir kartojimas
- Klaviatūra: `1`–`5` / `A`–`E`, `Enter` – toliau

Atidarykite `index.html` naršyklėje (arba įjunkite GitHub Pages).
